# RakVexa Main Website

Digital Growth & Software Solutions agency website.

## Stack

- Next.js
- React
- Tailwind CSS
- Lucide React

## Planned deployment

- Main: https://rakvexa.com
- Furniture demo: https://urbanwood.rakvexa.com
- Textile demo: https://textile.rakvexa.com
- Restaurant demo: https://restaurant.rakvexa.com
- Industrial demo: https://industrial.rakvexa.com

## Run locally

```bash
npm install
npm run dev
```

> Portfolio items are demo concepts until replaced with real client work.

## Contact / WhatsApp setup

Create `.env.local` and set `NEXT_PUBLIC_WHATSAPP_NUMBER` to RakVexa’s real WhatsApp number (digits only, including country code). The contact and free-audit forms then open WhatsApp with the submitted details.
